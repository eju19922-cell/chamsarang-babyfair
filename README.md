# 참사랑 베이비페어 상담 프로그램

베이비페어 부스에서 **산모님과 함께 보면서** 진행하는 상담 프로그램입니다.
파일 하나로 되어 있어 인터넷 없이도 열립니다.

## 바로 보기

👉 **https://eju19922-cell.github.io/chamsarang-babyfair/**

## 어떻게 쓰나요

1. 링크를 열고 **「상담 시작하기」**를 누르면 전체화면 상담 모드로 바뀝니다.
2. **「다음 →」** 버튼만 누르면 상담이 순서대로 흘러갑니다.
3. 끝내려면 `Esc`.

### 조작

| 조작 | 하는 일 |
|---|---|
| `→` / `←` 또는 화면을 좌우로 쓸기 | 다음 / 이전 |
| **☰ 목차** | 원하는 단계로 바로 이동 |
| **대본** 또는 `N` | 상담자 대본·체크리스트 (산모님께는 안 보임) |
| `F` | 자주 묻는 질문 · 반론 대응 즉답 |

터치 노트북과 터치 안 되는 노트북 모두 쓸 수 있습니다.

## 상담 흐름 (13단계)

| 묶음 | 내용 |
|---|---|
| **서비스안내** | 정부지원 산후도우미란? → 제공인력이 하는 일 → 제공인력의 하루 |
| **회사소개** | 참사랑어머니회 → 품질평가 A등급 → 정기 교육·간담회 → 왜 참사랑인가 |
| **요금안내** | 요금은 이렇게 이루어져요 → 내 본인부담금 계산 |
| **추가 안내** | 무료 산모교실 → 건강관리사 양성교육 |
| **예약** | 예약 진행 절차 → 마무리 |

산모님이 직접 고르시던 설문(유형 찾기 · 걱정 해소 · 맞춤 배정)은 2026.10.26. 직원 의견에 따라 삭제했습니다.
예전에 저장된 상담 기록의 설문 응답은 기록 화면과 엑셀 내보내기에서 그대로 보입니다.

## 요금 계산

창원시 2026년 고시표를 그대로 반영했습니다.

- 서비스가격 = 정부지원금 + 본인부담금
- 창원시 환급 = 본인부담금 × 90% (**최대 15일까지**, 초과분은 전액 본인 부담)
- 창원시 환급 대상 = 기준중위소득 **180% 이하**

서비스가격 54건 + 환급액 54건, **총 108개 항목을 원본 표와 대조해 전부 일치**를 확인했습니다.

## 사진 넣기

`images` 폴더에 정해진 이름으로 파일을 넣으면 화면에 자동으로 나타납니다.
어떤 사진을 어떤 이름으로 넣는지는 [`images/사진_넣는_방법.txt`](images/사진_넣는_방법.txt)에 있습니다.

사진이 없으면 "여기에 넣으세요" 안내 상자가 대신 보이며, 상담에는 지장이 없습니다.

## 아직 채워야 할 것 (담당자 확인)

프로그램 안에 주황색 **「담당자 확인」** 배지로 표시해 두었습니다. 추측해서 채우지 않았습니다.

- 지점 수 (전국 50개 vs 21개, 양산지점 포함 여부)
- 연간 보수교육 · 간담회 운영 횟수
- 관리사 교체 기준 (최대 횟수, 접수 방법, 담당자 연락처)
- 큰아이 추가요금 — 하루·1명 기준 종일 10,000원 / 5시 이전 하원 5,000원 / 5시 이후 하원 3,000원 (본인부담금 외 별도, `BIGKID_FEE`에서 수정)
- 주말·공휴일 추가요금
- 예약금 취소 · 환불 규정
- 상담자료에 노출할 대표 연락처
- 회사 표준일정표 (현재는 상담대본 기준 임시)
- 실제 관리사 배정 절차와 반영 항목
