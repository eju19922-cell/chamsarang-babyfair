## 먼저 읽어주세요

**1. 글자는 절대 넣지 마세요.** 프로그램이 한글 설명을 직접 넣습니다. AI가 만든 한글은 대부분 깨집니다.

**2. 영어 프롬프트를 쓰세요.** 제미나이는 영어로 넣을 때 결과가 훨씬 좋습니다.
아래는 **영어 프롬프트(복사해서 넣으세요)** + **한글 설명(무슨 그림인지)** 을 같이 적었습니다.

**3. 만든 뒤** `images` 폴더에 **파일 이름 그대로** 저장하시면 프로그램에 자동으로 뜹니다.

**4. 톤 통일 팁** — 첫 장이 마음에 들면 그 이미지를 올리고
`Same style and color palette as this image, but now showing: ...` 라고 하면 톤이 통일됩니다.

# 잘 안 나올 때

| 증상 | 해결 |
|---|---|
| 한글·영어 글자가 들어감 | 프롬프트 **맨 앞**에 `No text. No letters. No words.` 를 한 번 더 |
| 얼굴이 어색함 | `medium shot, faces slightly away from camera` 추가 |
| 톤이 제각각 | 첫 이미지를 올리고 `Same style and palette as this image, but now: ...` |
| 너무 사진 같음 | `soft watercolor illustration` 을 앞에 강조, `photorealistic` 절대 쓰지 않기 |
| 서양인이 나옴 | `Korean` 을 인물마다 붙이기 (Korean caregiver, Korean mother) |
