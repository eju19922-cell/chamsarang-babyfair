```

각 카드는 위에 굵은 항목명, 아래에 작은 설명 한 줄:

1. 서비스품질 — 서비스가 제대로 제공되는가
2. 인력관리 — 어떤 분을 뽑고 어떻게 관리하는가
3. 교육훈련 — 얼마나 자주, 무엇을 교육하는가
4. 안전관리 — 사고 예방과 대응 체계가 있는가
5. 고객만족도 — 실제 이용한 분들의 평가

각 카드에 항목에 어울리는 작고 단순한 아이콘을 하나씩 넣어 주세요
```
